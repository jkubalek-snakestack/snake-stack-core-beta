# Snake Stack Core beta

## Current beta: 0.82.0

[Download Core 0.82.0](https://github.com/jkubalek-snakestack/snake-stack-core-beta/releases/tag/v0.82.0-beta), or use the download button beside **Setup** in the game. Every player and Observer should use the same release (**multiplayer protocol 23**). Existing saves and preferences stay on each device.

- **On this screen** in Multiplayer offers independent boards and controls: two landscape tablet seats, or up to four TV/desktop seats when enough controllers and readable space are available. Phones keep one board.
- Browse ten original Stack Tracks album covers, explicitly **Listen**, and keep the earlier catalogue in **Archive**. Deeper options and the playable **Cadence** and cooperative **Ensemble** prototypes stay in a compact overlay.
- Richer character materials, handling sounds, song-specific instrumental responses and authored music/visual cues.
- Personal keyboard/controller controls and single-switch scanning; selected multi-stage Merriton finales and optional chapter mastery replays.
- Clearer actual CPU decisions, synchronized public match replay, requested family construction coaching and safer recovery. Hidden hands remain private.
- Versioned, signed music/art packs support future catalogue updates while saved rounds retain their original editions. The included catalogue works offline.

Windows, Android and Fire OS beta downloads are on the release page. Android includes ARMv7, ARM64 and x86_64, including 32-bit Fire TV hardware. Install over the existing app to retain local player data.

The final Windows runtime passed all 42 existing native suite areas, separate shared-screen/content-pack acceptance and actual host/guest checks. Android compilation, signing identity and 16 KB alignment are verified separately from physical-device acceptance. Fire TV/iPad performance and controller comfort still need device testing. The current iOS handoff is an unsigned Xcode export; Apple enrollment, Mac compilation/signing and TestFlight upload remain pending.

[Signed beta update feed](https://github.com/jkubalek-snakestack/snake-stack-core-beta/releases/download/beta-feed/beta.json). The game checks the signed notice and verifies package size and hash. Installation begins when the player chooses it after leaving active play.
