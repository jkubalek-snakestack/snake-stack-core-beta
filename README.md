# Snake Stack Core beta

## Current beta: 0.81.0

[Download Core 0.81.0](https://github.com/jkubalek-snakestack/snake-stack-core-beta/releases/tag/v0.81.0-beta), or use the download button beside **Setup** in the game. Every player and Observer should use the same release (**multiplayer protocol 23**). Existing saves and preferences stay on each device.

- Ten new, independently written Stack Tracks compositions with recorded instruments, distinct arrangements and adaptive musical development.
- The earlier ten songs remain available in **Archive**; existing story music, journeys and saved rounds keep their identities.
- Cleaner song selection and round setup, with detailed options in dismissible overlays.
- Stronger optional beat precision and word streaks. New solo Tracks uses word values multiplied by 100, plus up to 50% rhythm credit; thinking time has no deadline. Ordinary Core and multiplayer scoring stays unchanged.
- Clearer checkmarks, dropdown selections and arrows across all themes, plus improved musical transitions and recovery.

Windows, Android and Fire OS beta downloads are on the release page. Android includes ARMv7, ARM64 and x86_64, including the 32-bit Fire TV Cube. Install over the existing app to retain local player data.

The final Windows runtime passed 42 isolated native suite areas. Android compilation, signing identity, complete packaging and 16 KB alignment are verified separately from physical-device acceptance. The current iOS handoff is an unsigned Xcode export; Mac compilation, Apple signing and TestFlight upload remain pending.

[Signed beta update feed](https://github.com/jkubalek-snakestack/snake-stack-core-beta/releases/download/beta-feed/beta.json). The game checks the signed notice and verifies package size and hash. Installation begins when the player chooses it after leaving active play.
